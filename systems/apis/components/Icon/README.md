# Icon

**Classi:** inline `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">`

Scopo: disegnare un'icona del set interno di Apis, nello stesso stile di Lucide (griglia 24px, tratto 2px, terminali arrotondati).

**Chi lo usa fornisce:** `name` (`circle-info`, `circle-check`, `triangle-alert`, `octagon-x`, `hexagon`, `hexagon-plus`, `arrow-right`, `plus`, `search`, `download`), opzionali `size` (16, 24, 32) e `label`. Senza `label` l'icona è decorativa e nascosta agli screen reader. Il colore viene da `currentColor`.

Per tutte le altre icone usa Lucide con `strokeWidth={2}` e le stesse dimensioni.
