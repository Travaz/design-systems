# Changelog

One line per release: date · version · what changed. Versions follow semver (see `governance.md`).

- 2026-11-14 · 1.7.1 · The brand book and the system description present Apis as a design system drawn from the nature of honeybees, no longer as the design system of a site. Where Apis is used is still set by the skill.
- 2026-11-14 · 1.7.0 · Apis is written in English so it can be generalised: brand book, component sheets and previews, token notes, skill, shared principles and governance, the template for new systems and the generated references. New "Craft" section with checkable taste rules from Taste Skill and Claude's frontend-design skill, adapted to Apis. Motion with Motion (motion.dev): `apis-motion-tokens.js`, generated from the tokens, and `apis-motion-presets.js` with presets for motion/react and helpers for plain JavaScript, plus rules for reduced motion, seconds, springs without bounce and exits. Component previews now use English sample content.
- 2026-10-28 · 1.6.0 · "Native app" treatment from the review with Impeccable and Taste Skill: SF Pro with Dynamic Type and Bricolage for display only, SF Symbols, a near-neutral ground, cards without borders, capsule buttons, one question per screen. New primitives `stone-50`, `stone-100`, `stone-800`, `stone-900`, `stone-975`, semantic tokens `app-ground`, `app-raised`, `app-fill` (contrast checked) and `radius-xl` (24px). For everyone: at most one overline per screen, no monospace for sentences and labels.
- 2026-10-27 · 1.5.0 · More precise motion, from Emil Kowalski (animations.dev), Impeccable and Taste Skill: tokens `motion-press-scale` (0.97), `motion-enter-scale` (0.96), `motion-rise` (16px), `motion-blur` (2px); rules on frequency, speed, exits, no bounces, interruption, origin and reduced motion; a table for SwiftUI. Scope extended to the Gym Harness iPhone app. In the DTCG `tokens.json`, motion tokens that are not durations or curves have the right type (`number`, `dimension`).
- 2026-10-06 · 1.4.1 · Scope: Apis applies to travaz.dev (the site and tools on the same domain), no longer to all internal apps; every other app has its own system in the collection. The skill says so in its description and asks which system to use outside travaz.dev. The "internal apps" treatment is now called "tools".
- 2026-10-05 · 1.4.0 · `DataTable`: new column option `nowrap` (class `is-nowrap`) for identifiers, dates and codes, which wrapped at the hyphen on phones ("2026-" / "116").
- 2026-10-05 · 1.3.0 · Fonts included: Bricolage Grotesque, Instrument Sans and JetBrains Mono in WOFF2 (Latin and Latin Extended, OFL licence) in `fonts/`, declared with `@font-face` in `tokens.css`. No requests to Google Fonts: visitor privacy, fonts available sooner, tests that do not depend on the network.
- 2026-10-05 · 1.2.1 · Documentation verified: contrast ratios in the brand book and in token notes are computed by the build (`{{contrast …}}`); fixes four declared values that were not true (borders 3.4:1, not 3.5; `accent-text` 5.3:1, not 5.4; text on yellow 10.5:1; yellow on the ground 1.6:1). Documented the props `variant`, `size`, `as`, `titleAs`; removed the dead prop `optionalLabel`.
- 2026-10-05 · 1.2.0 · Identity: fluid display styles and a new `display-xl`; motion as part of the system (tokens `duration-reveal`, `duration-stagger`, `ease-emphasis`, classes `data-ap-reveal`, `ap-rise`, `ap-cell-in`, `ap-cell-open`, script `apis-motion.js`); dosage rules for the hexagon and yellow; guidelines for images and the logo; `aspect-*` tokens; `surface-inverse` stays dark in the dark theme too.
- 2026-10-05 · 1.1.0 · Apis lives in the `design-systems` collection: a single source (`tokens.json`, `css/`, `components/`, `docs/`) generates the skill, the package, the published design system files and the copies in the sites. Automatic checks for contrast, grid and token usage.
- 2026-10-01 · 1.0.1 · The base link style (`:where(.ap-base a:not([class]))`) has zero specificity and no longer overrides links styled by the site or by components. First application: the travaz.dev homepage.
- 2026-10-01 · 1.0.0 · First version: 78 colour tokens (42 primitives, 36 semantic), 13 text styles, 11 components + Icon, logo, site and app templates.
