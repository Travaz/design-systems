# Logos

- `apis-mark.svg` — The mark: a honeycomb cell (pointy-top hexagon) in `accent` with two bands in `carapace`. Fixed colours, works on light and dark `surface`. Minimum size 16px; clear space around it equal to half its width.
- `apis-mark-mono.svg` — Line version, a single ink: `carapace` (#1A1612). For monochrome print, favicons on a light background, stamps. Inline in HTML, replace the colour with `currentColor` to recolour it.

The name is written "Apis" in Bricolage Grotesque 700 next to the mark; there is no separately drawn logotype.
